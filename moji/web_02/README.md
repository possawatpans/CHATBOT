# 🎮 Pixel Adventure Portfolio

เว็บไซต์พอร์ตฟอลิโอส่วนตัวสไตล์เรโทร **8-Bit RPG** ที่ผสานการแนะนำตัว ข้อมูลการศึกษา ทักษะ ผลงาน และระบบแชท เข้ากับมินิเกมเดินสำรวจแผนที่แบบเรียลไทม์

---

## ✨ ฟีเจอร์หลัก

* **แถบสถานะสไตล์ RPG (HUD):** แสดง `HP`, `LV.` (อัปเลเวลเมื่อสำรวจข้อมูลครบ), `GOLD` และปุ่มสลับธีมระหว่างโหมดกลางคืน (`🌙 DUNGEON`) กับโหมดกลางวัน (`☀️ SUNNY`)
* **เอฟเฟกต์ข้อความพิมพ์ดีด (Typewriter Effect):** ข้อความต้อนรับที่ค่อยๆ พิมพ์ทีละตัวอักษรพร้อมเคอร์เซอร์กระพริบ
* **ระบบป๊อปอัปข้อมูลครบทุกหมวด:**
  * **★ ABOUT ME & CONTACT:** ข้อมูลส่วนตัว ปุ่มติดต่อทางอีเมล (คัดลอกอีเมล / เปิด Gmail / เปิดแอปเมล) และปุ่ม LINE (แสดง QR Code + คัดลอก LINE ID)
  * **🎓 การศึกษา:** ข้อมูลการศึกษาและความสนใจด้านเทคโนโลยีและเว็บเรโทร
  * **⚡ ทักษะ:** รายการทักษะด้าน Frontend และเครื่องมือพัฒนาที่ใช้
  * **📁 ผลงาน:** รายละเอียดผลงานและปุ่มลิงก์ไปดูบน GitHub
  * **💬 แชทกับอัศวิน:** หน้าต่างเลือกคำถาม-คำตอบอัตโนมัติสไตล์เกมย้อนยุค
* **มินิเกมแผนที่ `PIXEL WORLD EXPLORER` (ปุ่ม `▶ START GAME`):**
  * เดินบังคับตัวละครได้ทั้งปุ่ม `WASD` / `ไ ฟ ห ก` / ปุ่มลูกศร หรือ **คลิกบนฉาก** เพื่อให้เดินไปยังจุดที่เลือก
  * มีจุดหมายบนแผนที่ **5 จุด** ได้แก่ `🏰 GUILD HALL`, `🎓 การศึกษา`, `⚡ ทักษะ`, `📁 ผลงาน` และ `🛡️ อัศวิน`
  * มีตัวนับความคืบหน้าแบบเรียลไทม์ (`📍 จุดที่สำรวจ: X / 5`)
  * **มอนสเตอร์วิ่งไล่ (`👾 MONSTER`):** คอยไล่ตามผู้เล่นในฉาก หากโดนจับก่อนสำรวจครบจะเข้าสู่หน้าจอ **`💀 GAME OVER`** พร้อมภาพประกอบและปุ่มเล่นใหม่อีกครั้ง
  * **รางวัลชนะภารกิจ (`🏆 QUEST CLEAR!`):** หากเดินสำรวจครบทั้ง 5 จุดโดยไม่โดนมอนสเตอร์จับได้ จะปลดล็อกรางวัลพิเศษ ภาพประกอบชัยชนะ และโบนัส `+1,000G`

---

## 🕹️ วิธีเล่นมินิเกม

1. คลิกปุ่ม **`▶ START GAME`** ที่หน้าหลักเพื่อเปิดหน้าต่างแผนที่ `PIXEL WORLD EXPLORER`
2. ใช้ปุ่ม **`WASD`** (หรือ **`ไ ฟ ห ก`** / ปุ่มลูกศร) หรือ **คลิกซ้ายบนฉาก** เพื่อเดินหลบมอนสเตอร์และเดินไปชนจุดหมายทั้ง 5 แห่ง
3. เมื่อเดินถึงแต่ละจุดจะมีป๊อปอัปข้อมูลเด้งขึ้นมา (ระบบจะพักการไล่ของมอนสเตอร์ชั่วคราวขณะเปิดป๊อปอัปข้อมูล)
4. สำรวจให้ครบ **5 / 5 จุด** โดยไม่โดนจับเพื่อรับรางวัล **`🏆 QUEST CLEAR!`** หรือกด **↻ เล่นใหม่อีกครั้ง** หากโดนจับได้
